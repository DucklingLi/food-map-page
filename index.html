➕ 怎么添加一个新城市？

  1. 把新城市的数据文件传到数据仓库 food-map-data：美食文件（格式与 data.json 完全一致的数组）和 xxx_citywalk.json（{"version":2,"spots":[],"routes":[]}）。
  2. 在本仓库的 cities.json 的 cities 数组里复制一段配置，改 id、name、emoji、tagline、center（城市中心经纬度）、zoom 和两个数据文件名即可。
  3. 用本地编辑版切换到该城市录入数据，保存到 GitHub 后刷新本页就行 —— 网页代码一个字都不用改。
{
  "id": "hangzhou",
  "name": "杭州",
  "emoji": "🌿",
  "tagline": "西湖边走边吃",
  "regions": "西湖 · 上城 · 拱墅",
  "accent": "#16a085",
  "center": [30.26, 120.16],
  "zoom": 13,
  "food": "hangzhou.json",
  "citywalk": "hangzhou_citywalk.json",
  "enabled": true
}
